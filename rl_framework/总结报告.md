# 设计总结与实验分析

## 1. MDP 设计阐述

### 1.1 状态空间：为何选择原始 IQ 信号

选择原始时域复数信号（实部 + 虚部作为双通道输入）作为状态空间，基于以下考量：

1. **信息保留最完整**：IQ 信号包含幅度和相位信息，相比于仅使用距离像（幅度谱），保留了频域特征。不同干扰类型（扫频干扰、噪声调频、灵巧干扰等）在时域波形上有显著差异，CNN 可以自动学习这些差异特征。

2. **与抗干扰算法接口一致**：现有抗干扰算法（WLN、频域对消、自适应滤波等）均工作在时域或频域的原始信号上，使用 IQ 信号作为输入避免了额外的信息损失。

3. **端到端学习优势**：将特征提取交给 1D-CNN，避免手工设计特征的局限性。CNN 可以学习到与干扰类型、强度相关的多层次特征。

4. **辅助干扰 one-hot**：在特征提取阶段拼接干扰类型 one-hot 向量，帮助网络快速区分不同干扰场景，加速策略收敛。在训练时该信息可用，在部署时若干扰类型未知可以移除或使用估计值。

同时提供 `range_profile` 模式作为对比实验基线，验证原始 IQ 输入的优势。

### 1.2 动作空间设计

采用**混合动作空间**（离散 + 连续），原因如下：

- **离散动作**对应抗干扰算法选择。不同算法针对不同干扰类型有显著差异（如 WLN 适合压制性干扰、频域对消适合瞄准式干扰），智能体需要学会根据干扰类型选择最合适的算法。

- **连续动作**对应算法参数调优。即使是同一算法，不同参数对性能影响很大（如 WLN 的限幅阈值、FrFT 的旋转阶数），连续参数使智能体能精细调节。

- 两者耦合：算法选择决定参数空间的有效维度。网络始终输出所有连续参数，环境根据离散动作选取有效维度。

### 1.3 奖励函数

```
r = w_sinr * (SINR_after - SINR_before) + w_detect * I(detection)
```

- **SINR 改善**作为主奖励：直接反映抗干扰效果，单位 dB，物理意义明确。
- **检测奖励**作为辅助：鼓励智能体不仅改善 SINR，还要使目标超过检测阈值。
- 设计为增量奖励（改善量而非绝对值），使奖励尺度与干扰强度无关。

## 2. 网络结构与 PPO 更新公式

### 2.1 网络结构

```
输入信号 (B, 2, 1024)          输入 one-hot (B, J)
        │                              │
        ▼                              │
   ┌─────────┐                         │
   │ Conv1d  │ 16ch, k=11, s=4         │
   │ BN+ReLU │                         │
   │ MaxPool │ k=3, s=2               │
   ├─────────┤                         │
   │ Conv1d  │ 32ch, k=7, s=3         │
   │ BN+ReLU │                         │
   │ MaxPool │ k=3, s=2               │
   ├─────────┤                         │
   │ Conv1d  │ 64ch, k=5, s=2         │
   │ BN+ReLU │                         │
   │ MaxPool │ k=3, s=2               │
   ├─────────┤                         │
   │ Conv1d  │ 128ch, k=3, s=1        │
   │ BN+ReLU │                         │
   │ MaxPool │ k=3, s=2               │
   ├─────────┤                         │
   │ Flatten │                         │
   │ Linear  │ → 256                   │
   │ ReLU    │                         │
   └────┬────┘                         │
        │                              │
        └──────────┬───────────────────┘
                   │
                   ▼
            拼接特征 (B, 256+J)
                   │
           ┌───────┴───────┐
           ▼               ▼
        Actor           Critic
     ┌──────────┐    ┌──────────┐
     │ Linear   │    │ Linear   │
     │ Tanh     │    │ Tanh     │
     │ Linear   │    │ Linear   │
     │ Tanh     │    │ Tanh     │
     ├──────────┤    │ Linear   │
     │┌────┐┌──┐│    │ → 1      │
     ││dsc ││c ││    └──────────┘
     ││head││  ││
     ││→K  ││m ││
     ││    ││s ││
     │└────┘└──┘│
     └──────────┘
```

**Actor 输出**：
- 离散 logits → Categorical 分布 → 算法选择
- 连续 mean (经 tanh) + log_std → Gaussian → tanh squashing → [0, 1] 参数值

**Critic 输出**：标量 V(s)

### 2.2 PPO-Clip 更新公式

**优势估计 (GAE)**：
```
δ_t = r_t + γ * V(s_{t+1}) * (1 - d_t) - V(s_t)
A_t = δ_t + γ * λ * (1 - d_t) * A_{t+1}
R_t = A_t + V(s_t)
```

**裁剪目标函数**：
```
L^{clip}(θ) = E_t[ min(r_t(θ) * A_t, clip(r_t(θ), 1-ε, 1+ε) * A_t) - c_1 * H(π_θ) ]
```
其中 `r_t(θ) = π_θ(a_t|s_t) / π_{θ_old}(a_t|s_t)`

**连续动作 tanh 校正**：
```
log π(squashed) = log π_gaussian(pre_squash) - Σ log(1 - tanh²(pre_squash))
```

**价值裁剪**（可选）：
```
V_clip = V_old + clip(V_new - V_old, -ε_v, ε_v)
L_V = max(MSE(V_new, R), MSE(V_clip, R))
```

## 4. 预期实验结果

### 4.1 训练曲线趋势

- **前 200 回合**：随机探索阶段，奖励波动大，平均 SINR 改善接近 0（随机策略的期望改善）。
- **200-1000 回合**：快速学习阶段，智能体开始学会针对不同干扰类型选择合适的算法，平均奖励显著上升。
- **1000-3000 回合**：精细调优阶段，连续参数逐渐收敛到较优范围，奖励增长放缓。
- **3000+ 回合**：收敛阶段，奖励曲线趋于稳定，可能出现小幅振荡。

### 4.2 模式对比

- **raw_iq vs range_profile**：预期 raw_iq 模式收敛更快、最终性能更好，因为保留了更丰富的信息。range_profile 模式可能对某些频域特征明显的干扰表现较好。
- **不同干扰类型**：对压制性干扰（FMZuse、AMNoiseGaiJam）改善较大，对灵巧干扰（RGPO）改善较小。

### 4.3 策略分析

预期智能体能学到类似以下的策略映射：
- FMNoiseAimedJam → WLN（低阈值限幅）
- FMZuse → FrequencyDomainCanceller
- SMSP → adapt_filter
- 弱干扰场景 → 保守策略（避免过度处理）

## 5. 局限性与改进方向

### 5.1 当前局限

1. **强干扰下信号淹没**：当 JSR 极高时（> 30 dB），目标信号在时域几乎不可见，CNN 难以提取有效特征。这是所有基于接收信号观察的方法的共同困难。

2. **混合动作空间探索**：离散-连续混合空间的探索效率低于纯离散或纯连续空间。某些算法-参数组合可能很少被尝试。

3. **单脉冲决策**：当前每步只观察一个脉冲，缺少多脉冲上下文信息。实际雷达系统通常利用脉冲间的相干性。

4. **干扰 one-hot 信息泄露**：训练时使用干扰类型 one-hot 作为辅助输入，部署时如果干扰类型未知需要额外分类器或改为不使用。

5. **训练时间需求**：每步需要生成干扰信号 + 调用抗干扰算法 + 脉冲压缩，单步耗时较长（约 10-50ms），5000 回合可能需要数小时。

### 5.2 改进方向

1. **时频特征提取**：加入 STFT 或小波变换作为额外输入通道，帮助网络捕获频域干扰特征。

2. **RNN / Transformer 编码器**：将 1D-CNN 替换或增强为 LSTM / Transformer，利用多脉冲时序信息。

3. **注意力机制**：在特征提取中加入 Self-Attention，帮助网络聚焦于信号中被干扰影响的关键区域。

4. **课程学习**：从低 JSR 开始训练，逐步增加干扰强度，缓解强干扰下的学习困难。

5. **多智能体 / 层级策略**：高层策略选择算法类别，低层策略微调参数，分解混合动作空间的复杂度。

6. **预训练 + 迁移学习**：在有标签数据上预训练特征提取器（干扰分类任务），再微调 RL 策略。

7. **仿真到现实 (Sim2Real)**：增加信道模型、杂波等更真实的场景因素，提高模型的鲁棒性。
