# 干扰机马尔可夫状态转移模型

> 日期: 2026-05-20
> 状态: 方案设计，待实现
> 来源: 用户原创方案

---

## 一、核心思想

干扰机不再是"一招用到底"，而是根据雷达抗干扰的**效果**动态切换干扰策略：

- **抗干扰有效** (r_t 高) → 干扰机被迫升级到更强的压制策略
- **抗干扰无效** (r_t 低) → 干扰机维持或降级到更精确的欺骗策略

这创造了真正的**时序博弈**：agent 每步的动作直接影响下一步面对的干扰类型。

---

## 二、5 状态定义与干扰映射

```
精确欺骗                        粗暴压制                        信号污染
  ← 低功率/高精度                                   高功率/低精度 →

S1 ←→ S2 ←→ S3 ←→ S4 ←→ S5
```

| 状态 | 代号 | 含义 | 干扰类型 | 干扰特征 |
|------|------|------|---------|---------|
| S1 | 脉内采样欺骗 | 在单个脉冲内采样转发 | ISDJ, SMSP | 精确但脆弱，容易识别 |
| S2 | 脉间采样欺骗 | 跨脉冲采样欺骗 | RGPO | 依赖多脉冲结构，中等精度 |
| S3 | 瞄准式压制 | 针对特定频段的噪声压制 | FMNoiseAimedJam, AMNoiseGaiJam | 功率集中，频段窄 |
| S4 | 覆盖式压制 | 宽带扫频/阻塞式噪声 | FMZuse, FMNoiseSaopin | 功率分散，覆盖宽 |
| S5 | 信号结构污染 | 直接污染信号结构 | NoiseProductJamming, NoiseConvolutionJamming | 最隐蔽，影响信号本质 |

### 映射逻辑

- **S1→S5 的"强度"递增**：从精确欺骗到粗暴压制到深层污染
- 每个状态包含 1-2 个具体干扰实现
- 进入某状态时，**随机选择**该状态下的一个干扰器
- 状态内保持同一干扰器直到发生状态转移

## 三、转移概率模型

### 抗干扰效果度量

```
r_t = max(0, SINR_after - SINR_before) / max(|SINR_before|, ε)
r_t ∈ [0, 1]，越高表示抗干扰越有效
```

### 转移概率公式 (归一化版)

对非边界状态 i ∈ {2, 3, 4}：

```
p_escalate = 0.6 × r_t          # 升级倾向 (向 S5 方向)
p_deescalate = 0.6 × (1 - r_t)  # 降级倾向 (向 S1 方向)
p_stay = 1 - p_escalate - p_deescalate = 0.4  # 固定维持概率

# 升级分配: 邻近升级 70%，跳跃升级 30%
P(i → i+1) = p_escalate × 0.7 = 0.42 × r_t
P(i → i+2) = p_escalate × 0.3 = 0.18 × r_t

# 降级分配: 邻近降级 70%，跳跃降级 30%
P(i → i-1) = p_deescalate × 0.7 = 0.42 × (1-r_t)
P(i → i-2) = p_deescalate × 0.3 = 0.18 × (1-r_t)

# 维持
P(i → i) = 0.4
```

**验证**: 0.4 + 0.42r + 0.18r + 0.42(1-r) + 0.18(1-r) = 0.4 + 0.6r + 0.6 - 0.6r = **1.0** ✓

### 边界处理

| 状态 | 处理方式 |
|------|---------|
| S1 (左边界) | 无降级方向 → P(i→i-1) 和 P(i→i-2) 合并入 P_stay |
| S5 (右边界) | 无升级方向 → P(i→i+1) 和 P(i→i+2) 合并入 P_stay |

具体：

**S1** (只有升级方向):
```
P(S1 → S1) = 0.4 + 0.42(1-r_t) + 0.18(1-r_t) = 1.0 - 0.6×r_t
P(S1 → S2) = 0.42 × r_t
P(S1 → S3) = 0.18 × r_t
```

**S2** (降级只有 S1):
```
P(S2 → S2) = 0.4
P(S2 → S3) = 0.42 × r_t
P(S2 → S4) = 0.18 × r_t
P(S2 → S1) = 0.42 × (1-r_t)
P(S2 → S0) → 合并入 P_stay: P(S2→S2) += 0.18(1-r_t) = 0.4 + 0.18(1-r_t)
修正: P(S2→S1) = 0.6 × (1-r_t)   # 全部降级概率给 S1
      P(S2→S2) = 0.4
      P(S2→S3) = 0.42 × r_t
      P(S2→S4) = 0.18 × r_t
```

**S4** (升级只有 S5):
```
P(S4→S4) = 0.4
P(S4→S5) = 0.6 × r_t              # 全部升级概率给 S5
P(S4→S3) = 0.42 × (1-r_t)
P(S4→S2) = 0.18 × (1-r_t)
```

**S5** (只有降级方向):
```
P(S5 → S5) = 0.4 + 0.42×r_t + 0.18×r_t = 0.4 + 0.6×r_t
P(S5 → S4) = 0.42 × (1-r_t)
P(S5 → S3) = 0.18 × (1-r_t)
```

### 数值示例

| r_t | 含义 | P_escalate | P_deescalate | P_stay |
|-----|------|-----------|-------------|--------|
| 0.0 | 抗干扰完全无效 | 0.0 | 0.6 | 0.4 |
| 0.3 | 抗干扰效果一般 | 0.18 | 0.42 | 0.4 |
| 0.5 | 抗干扰中等有效 | 0.30 | 0.30 | 0.4 |
| 0.8 | 抗干扰高度有效 | 0.48 | 0.12 | 0.4 |
| 1.0 | 抗干扰完全压制 | 0.6 | 0.0 | 0.4 |

## 四、Episode 流程 (改进后)

```
reset():
  1. 初始状态 S_init ∈ {S1, S2, S3, S4, S5} (随机或固定 S3)
  2. 从 S_init 中随机选一个干扰器
  3. 生成含干扰脉冲 → 返回 state

step(action):
  1. 解码 action → (算法, 参数)
  2. 抗干扰处理 → 计算 SINR_before, SINR_after
  3. 计算 r_t = max(0, SINR_after - SINR_before) / max(|SINR_before|, ε)
  4. 计算 reward (基于 SINR 改善)
  5. 基于当前状态和 r_t 计算转移概率
  6. 采样新状态 → 从新状态中选干扰器
  7. 生成下一个含干扰脉冲 → 返回 (state, reward, done, info)

8 步后 done=True
```

### 与原方案的对比

| 维度 | 原方案 | 马尔可夫模型 |
|------|--------|------------|
| 步间依赖 | 无 | **强** (当前动作影响下一步干扰) |
| 干扰类型 | 固定一种 | **动态切换** (5种状态 × 2种实现) |
| 最优策略 | 静态映射 | **时序策略** (需预判干扰升级) |
| GAE 价值 | 无用 | **有效** (跨步信用分配有意义) |
| CPPO 优势 | CNN 每步重复特征提取 | **每步信号特征不同** |

## 五、为什么这个方案优于之前的方案 A-E

| 对比 | 马尔可夫模型 | 方案A(JSR渐进) | 方案B(类型切换) | 方案D(对抗博弈) |
|------|------------|--------------|--------------|--------------|
| 时序依赖 | 动作驱动 | 预设梯度 | 随机切换 | 双重RL |
| 物理合理性 | 高 (干扰机自适应) | 高 | 中 | 最高 |
| 实现复杂度 | **低** | 低 | 低 | 极高 |
| 训练稳定性 | **稳定** | 稳定 | 稳定 | 不确定 |
| 论文叙事性 | **好** (博弈论+马尔可夫) | 一般 | 一般 | 非常好 |

**关键优势**：
1. 不需要训练"智能干扰器" (方案D的痛点)
2. 干扰切换有物理意义 (自适应电子战)
3. 时序依赖由 agent 的动作驱动 (不是预设的，方案A的弱点)
4. 实现简单 (只需改 environment.py 的 step() 和 reset())

## 六、实现计划

### 改动文件

1. **`rl_framework/config.py`**
   - 新增 `jammer_states` 字典: 状态 → 干扰列表
   - 新增转移概率参数: `escalate_weight=0.6`, `adjacent_ratio=0.7`
   - 新增 `initial_state = 3` (默认从 S3 开始)

2. **`rl_framework/environment.py`**
   - `reset()`: 初始化状态，选干扰器
   - `step()`: 计算 r_t → 状态转移 → 选新干扰器 → 生成脉冲
   - 新增 `_compute_transition()` 方法
   - 新增 `_sample_jammer_from_state()` 方法

3. **不需要修改的文件**
   - 干扰器本身 (接口不变)
   - 抗干扰算法 (接口不变)
   - PPO 网络 (输入维度不变，one-hot 从 9→5 或保持 9)

### one-hot 维度选择

两种方案：

**方案 1: 保持 9 维 one-hot** (推荐)
- 网络输入不变，无需修改网络结构
- agent 需要从信号特征推断具体干扰类型
- 代码改动最小

**方案 2: 改为 5 维状态 one-hot**
- 网络输入维度变化，需要修改网络
- agent 只知道状态等级，不知道具体干扰类型
- 更有挑战性，但信息更少

## 七、扩展方向

1. **非对称转移**: 某些状态之间的转移概率不同 (如 S3→S4 比 S3→S2 更容易)
2. **JSR 联动**: 状态升级时同步增加 JSR (结合方案 A)
3. **记忆效应**: 保留最近 N 步的 r_t 历史，用均值决定转移
4. **状态停留惩罚**: 连续 N 步停留在同一状态时强制转移
5. **智能干扰器**: 用训练好的 RL agent 替代马尔可夫规则 (方案 D 的长期目标)
